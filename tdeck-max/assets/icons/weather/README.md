# MatterMesh Weather icon pack

Nine monochrome conditions: clear, partly cloudy, cloudy, fog, drizzle, rain, snow, storm, unknown. Native 64px vector master, consistent solid strokes and no shades. Editable source: `src/ui/weather_icons.h`. Firmware rasterizes directly; no additional runtime dependencies or downloaded artwork. Launcher/Home use the same partly-cloudy glyph with selected-state inversion.

PNG/PBM exports at 24 and 64 pixels generated by `sim/weather_icons_preview.cpp`, compiled with the same Adafruit GFX native stubs as tools/render_ui.sh. PBM is the authoritative 1-bit raster. Unknown WMO codes show a cloud/question mark rather than a false condition. Existing weather networking/data/storage are unchanged.
